- 패키지 무결성, 슬라이드 크기, 글꼴 정책, 재가져오기 검사를 통과했고 최종 PPTX 전체를 다시 렌더링해 글자 잘림·겹침·슬라이드 경계 이탈이 없음을 확인했다.

## 24. 2026-09-16 감성 중심 서비스 차별화 슬라이드 제작

- 기존 트리플·Mindtrip·우리 프로젝트 비교표를 참고해 `docs/presentations/감성중심_서비스_차별화.pptx` 한 장을 제작했다.
- 우리 프로젝트의 차별화 방향을 여행 조건 입력뿐 아니라 사용자가 떠나고 싶은 이유와 마음을 일정의 속도·장소 분위기·활동에 반영하는 흐름으로 정리했다.
- 비교표 전체를 편집 가능한 PowerPoint 표로 구성하고, 우리 프로젝트 열과 핵심 차별점 문장을 시각적으로 강조했다.
- 패키지 무결성, 슬라이드 크기, 글꼴 정책, 편집 가능한 표와 재가져오기 검사를 통과했으며 최종 슬라이드를 렌더링해 글자 잘림·겹침이 없음을 확인했다.
- 이번 작업은 발표 자료 제작이며 애플리케이션 코드, DB 스키마와 기능 구현은 변경하지 않았다.
- 1차 슬라이드가 감성 반영 방식을 구체적으로 설명하지 못해 `docs/presentations/감성중심_서비스_차별화_v2.pptx`로 보완했다. 자연어 감성 입력을 여행 의도로 해석한 뒤 시작 시각·이동 횟수·장소 유형·체류 시간·추천 이유에 연결하는 예시 흐름을 한 장에 정리했다.
- 비교 대상이 보이지 않는 v2의 한계를 보완해 `docs/presentations/감성중심_서비스_차별화_v3.pptx`를 제작했다. 트리플·Mindtrip·우리 프로젝트를 시작 질문, 감성 해석, 일정 반영, 결과 설명 기준으로 비교하고 같은 감성 문장이 우리 프로젝트에서 일정 생성 조건으로 변환되는 예시를 함께 표시했다.
- 슬라이드 제목을 요청에 따라 `다른 프로그램과의 차별성`으로 변경한 `docs/presentations/감성중심_서비스_차별화_v4.pptx`를 만들었다. 나머지 비교 내용과 편집 가능한 표 구조는 유지했다.
- 제목 표현을 `다른 프로그램과의 차이점`으로 다듬은 `docs/presentations/감성중심_서비스_차별화_v5.pptx`를 만들었다.
- 제목 아래 보조 문구를 제거한 `docs/presentations/감성중심_서비스_차별화_v6.pptx`를 만들고 나머지 요소는 유지했다.
- 최종 활용용으로 `같은 입력 예시` 영역을 제거하고 `핵심 차이` 문구를 위로 배치한 `docs/presentations/다른_프로그램과의_차이점.png`를 2560×1440 PNG 이미지로 내보냈다. 이 작업에서는 새 PPTX를 만들지 않았다.
- 감성의 정의를 여행 전후의 감정 변화로 구체화한 비교 이미지 `docs/presentations/감정변화_기반_서비스_차이점.png`를 2560×1440 PNG로 제작했다. 트리플·Mindtrip·우리 프로젝트를 추천 출발점, AI 역할, 감성의 위치, 일정 결과로 비교하고 우리 프로젝트의 현재 마음→여행 중 경험→돌아올 때의 마음 흐름을 함께 표시했다. 한글과 표의 정확성을 위해 생성형 이미지 대신 편집 가능한 도형·표를 이미지로 직접 내보냈으며 PPTX 산출물은 만들지 않았다.
- 비교표의 `감성의 위치` 행을 `일정 구성`으로 바꾸고 각 서비스의 구성 방식을 방문 동선, 시간대·지도 조정, 감정 변화의 하루 흐름 배치로 다시 비교한 `docs/presentations/감정변화_기반_서비스_차이점_v2.png`를 제작했다. 아래 `일정 결과` 행도 구성 방식과 겹치지 않도록 수정·관리, 공유·예약 연결, 추천 이유 중심으로 정리했으며 새 PPTX는 만들지 않았다.
- 비교 기준의 `일정 구성`을 `세부 일정 계획`으로 변경하고, 감성을 고정된 여행 취향으로 분류하는 방식과 감정의 원인·기대 변화를 해석하는 방식을 대비한 `docs/presentations/감정변화_기반_서비스_차이점_v3.png`를 제작했다. 하단에는 피로와 답답함→조용한 시간→가벼워진 마음→이동 감소·체류 증가→멀어지는 날·쉬는 날·돌아오는 날의 흐름을 표시했다.
