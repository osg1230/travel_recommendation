# 조건 보완과 AI 일정 수정 요구사항 변경 내역

기준일: 2026-09-15

기준 문서: `창프2_요구분석서 3.1_일정배치방식반영_최종본.docx`. 기존 파일명·요구사항 번호·우선순위를 유지하고 문서 수정일을 갱신했다.

## 확정 범위

- R1 조건 입력: 자연어 또는 키워드 입력 → 부족하거나 모호한 조건 질문·답변 → 조건 확인·확정 → 추천 요청.
- 서버가 필요한 질문 항목을 판단한다. 정해진 질문 문구와 선택 버튼을 사용할 수 있으며 질문 생성 자체를 AI에 맡길 필요는 없다.
- 기존 확인값은 유지한다. 선택 조건은 미지정으로 진행할 수 있고 필수 조건을 AI 추정으로 확정하지 않는다.
- R2 일정 수정: 직접 편집과 현재 일정에 대한 자연어 AI 수정 요청을 지원한다. 현재 일정·조건·이번 요청·실제 장소 후보를 사용한다.
- 서버 검증을 통과한 수정안과 연관된 시간 변경을 보여주고 사용자가 적용·저장한다. 취소·실패 시 원본을 보존한다.
- 반복 수정은 가장 최근 적용한 일정 기준이다. 모호한 대상은 확인하며 오래된 수정안의 덮어쓰기를 막는다.
- 과거 대화 전체 기억, 자유 상담, 이전 일정 버전 복원은 현재 범위에서 제외한다.
- 사용자 수정 요청과 검증 실패 자동 자기수정을 구분한다. 요청 한 건의 일정 생성 호출은 최초 1회와 자기수정 최대 2회의 기존 상한을 적용한다.

## 반영 위치

프로젝트 범위, SFR-02-01·03·04, SFR-03-01·02, SFR-08-04의 목록·상세 정의·검증 기준, DAR-02·05, EIR-01, QUR-01·03, TER-02·04, AI 처리 원칙, UC-06·08 목록·시나리오와 추가 제안 반영 결과를 갱신했다. 화면 흐름도·추적표와 자연어 분석 문서에도 요구사항과 구현 상태를 구분해 기록했다.

## 확인 및 남은 작업

- DOCX 재열기와 OOXML 구조, 기존 요구사항 ID·표·이미지 보존 및 변경 전후 텍스트를 검사했다.
- `render_docx.py` 실행은 `LibreOffice soffice.exe was not found on PATH`로 실패했다. 번들에도 LibreOffice가 없어 페이지 이미지 생성과 시각 검증은 미완료이다. Word에서 표 넘침·페이지 나눔을 확인해야 한다.
- 이번 작업은 문서 변경이다. 질문·답변 보완과 AI 일정 수정 기능을 구현·실행 검증한 것이 아니다.
- DB 스키마는 변경하지 않았다. AI 수정안 임시 보관·현재 원본 비교 방식은 일정 구현 전에 기존 DB 설계와 대조하여 구체화한다. 전체 대화 기록이나 일정 버전 테이블 추가는 확정하지 않았다.
