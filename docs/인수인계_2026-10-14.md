### 4-2. 흐름·상태 안내 공통 보완 포인트

- **화면 간 이동**: 홈 → 조건 입력(문장/조건 고르기/취향 탐색/축제) → 추천 결과 → (장소 목록) → 여행 정보 → 일정 초안 → 수정/저장 → 내 일정. 장소 목록(UI-10 하단)은 '바로 일정 만들기'로 건너뛸 수 있어 흐름이 두 갈래다. 단계 표시(`flowSteps`)는 4단계 고정이라 취향 탐색·축제 진입 시 어색할 수 있다.
- **로딩 상태**: 폼 제출형 로딩은 `travel-analysis.js`(aria-busy)·`signup.js`·`place-discovery.js`·`bus-guide.js`·`home-trip.js`에만 있다. 참고 가격·비행기·수정안 생성·직접 수정·저장은 표시가 없다. 추천·일정 작업은 폴링 대기 화면이 있다.
- **빈 결과(Empty State)**: 마이페이지 목록(`my/*`)은 안내 상자 문구가 있다. 추천 후보 0곳, 장소 목록 후보 부족(관광지<5·음식점<3·숙소<2 → 카카오 자동 재조회), 축제 없음, 주변 지역 없음, 참고 가격 못 찾음 등은 문구가 있으나 화면마다 표현이 달라 통일 점검이 필요하다.
- **오류 안내**: 기능별 `*-error.html` 8개가 있고 형식이 비슷하다(제목·사유·돌아가기). 공통 조각으로 묶을 여지가 있다. OpenAI 크레딧 소진(`AI_QUOTA`)·요청 제한 화면은 단위 테스트만 통과했고 실제 화면은 미확인(10-04).
- **확인 창**: 삭제·취소·상태 변경 7곳이 네이티브 `confirm()`이다. 통일된 확인 UI로 바꿀지 결정.
- **비회원 안내**: `guest-session.html` 조각으로 30분 세션 만료를 안내한다. 만료 뒤 403/404로 떨어지는 경우의 복귀 동선(조건부터 다시) 점검.
- **지도**: 카카오 JavaScript 키 도메인 미등록이면 안내 문구로 대체된다. 다른 PC·포트는 콘솔 등록이 필요하다.
- **AI 문장 품질**: 추천 이유가 120자 지시를 넘기도 하고(스키마 상한 300자), 띄어쓰기 오류는 서버가 고치지 않는다(보완 사항 2-1). 화면에서 접기 또는 재요청 검토.
- **접근성**: 숨긴 입력·`aria-current`·`aria-expanded`·낭독기용 라벨이 있으나 전 화면 점검 기록은 없다.

## 5. 남은 작업 및 기술적 체크리스트 (To-Do)

### 5-1. 입력값 검증·엣지 케이스

- Bean Validation은 `SignupForm`·`ProfileForm`에만 있다. 조건 입력은 `TravelConditionValidator`(문장 1~2,000자, 지역 100자, 선택지 검증, 날짜·일수·예산 형식), 일정 입력은 `ItineraryGenerator.checkInput`(기간 1~7일, 08:00~21:00·4시간 이상, 체류 30~180분, 후보 부족)으로 수동 검증한다. 나머지 폼(평가·예약·직접 수정·버스·비행기·제목 수정)의 서버 검증 범위를 화면별로 점검한다.
- 지시 무시 문장이 섞이면 정상 부분("제주 여행")까지 함께 거부된다(10-04, 안전 쪽 동작으로 두었음). 안내 문구가 적절한지 확인.
- "11월 셋째 주 주말"을 겨울로 분류한 사례처럼 계절 판정은 모델 판단이다. 필요하면 `ai/condition-instructions.txt`에 기준을 적는다.
- 인원 세기("친구 둘이서" 2명 / "친구 둘과" 3명)는 지시문으로만 보정했다. 다른 표현은 보장하지 않는다.
- 참고 가격은 금액 전체 일치만 근거로 본다. 날짜·객실별 요금이 아니므로 예산 충족 판정은 하지 않는다.
- 섬 관광지(페리)는 이동시간 2시간 초과로 빠지며 필수 장소면 실패한다. 제주 왕복은 비행기로만 찾고, 못 찾으면 출발지를 비우라고 안내한다.
- 축제가 2일차 이후 시작하고 중심 장소가 모자라면 날짜를 못 맞추고 필수 방문으로만 들어간다(브라우저 미확인).
- 관광지를 뺀 수정안에서 다시 수정안을 만들면 빈 시간이 예비 관광지로 채워질 수 있다(10-05 알려진 한계).

### 5-2. 세션·권한

- 세션 30분, 쿠키 HttpOnly·SameSite=lax, 로그인 시 세션 ID 변경, CSRF 유지. 비회원 추천·초안은 세션 토큰으로만 소유권을 확인하고, 로그인 후 같은 세션에서 저장할 수 있다. 공용 PC 때문에 로그인 시 자동 옮기기는 제거했다(09-25).
