## 1. 장소 후보·중심 장소

### 1-2. 중심 장소가 GPT가 아는 이름에 의존함
- 중심 장소는 GPT가 추천 이유와 함께 적은 장소 이름과, 후보 한 곳에만 맞는 여행지 소개 단어로 고른다(`CenterPlaces.pick`). GPT가 적은 곳이 후보에 없으면 쓰지 못하고(예전 예: 안동 봉정사, 2026-09-24부터 사찰 검색으로 후보에 들어옴), 소개 단어가 여러 곳에 맞으면(예: "마을"·"서원") 건너뛴다.
- 검토 방향(2단계, DB 변경): 카카오 "○○ 명소" 검색 순위를 `places`에 저장해 대표성 판단에 쓴다. SQL 015·`Place`·`KakaoPlace`·`PlaceCandidate`·정렬·DB 정의서를 함께 바꿔야 하며, 다른 PC도 SQL 적용이 필요하다.

### 1-4. 예전 카카오 검색 결과가 24시간 동안 남음
- 관광지 검색 방식을 바꾸기 전(2026-09-23)에 저장된 카카오 장소는 24시간 캐시가 지나거나 '카카오에서 장소 더 찾아보기'로 다시 조회해야 새 결과로 바뀐다. 캐시가 지나면 저절로 해결된다. 2026-09-24에 추가한 사찰·성당 후보도 같은 방식으로, 재조회 전까지는 보이지 않는다.

## 2. AI 응답 품질

### 2-1. 추천 이유 길이·문장 품질을 보장하지 못함
- 추천 이유를 1~2문장·120자 안팎으로 지시했지만 GPT가 항상 지키지는 않는다(안동 약 160자, 스키마 상한 300자). 띄어쓰기 오류("함께해변을" 등)도 GPT 문장이라 서버가 고치지 않는다.
- 검토 방향: 화면에서 일정 길이를 넘으면 접어서 보여 주는 방법, 또는 서버에서 길이를 넘으면 한 번 다시 요청하는 방법.

### 2-2. 비슷한 곳 판단은 GPT가 함
- 문장 수정에서 후보에 없는 장소를 요청하면 비슷한 곳으로 바꾸는데, 어떤 곳이 비슷한지는 GPT가 고른다. "처럼·같은" 표현의 구분은 서버 규칙으로 보완했지만, 고른 장소가 사용자 기대와 다를 수 있다.

### 2-3. 되물은 기록이 세션에만 있음
- 콕 집은 장소를 한 번 되물었다는 기록은 세션에 둔다. 세션이 끝나면(30분 무동작·브라우저 종료) 같은 장소를 다시 되묻는다.

### 2-4. 추천 이유가 확인하지 않은 전시 내용을 단정함
- 2026-09-24 "아이랑 상어 보러 아쿠아리움" 추천에서 GPT가 "다누리아쿠아리움에서 상어를 볼 수 있으며", "상어 관람이 가능하지만"처럼 시설 이름만 확인한 곳의 전시 내용을 단정했다. 지시문은 확인이 필요하다고 쓰라고 하지만 지키지 않는다(현재 프롬프트 그대로 재현). 화면의 안내 문구("목적에 맞는 곳은 이름·주소만 확인했어요")로만 보완하고 있다.
- 검토 방향: "○○이 있어"처럼 시설 존재만 쓰게 지시를 바꿔 보았으나 같은 단정이 나와 되돌렸다. 서버에서 "볼 수 있", "가능" 같은 표현을 찾아 되묻거나 문장을 바꾸는 방법, 또는 추천 이유 아래에 시설별 확인 범위를 따로 적는 방법을 검토한다.

### 1-5. 카카오로 찾은 같은 장소에는 가상 예약이 붙지 않음
- 2026-09-26 강릉 1박 2일(오죽헌 목적) 일정에 오죽헌이 들어갔지만, 일정의 오죽헌은 카카오 장소(`places` 1015 '오죽헌')이고 가상 수량은 시스템 장소(4 '오죽헌·시립박물관')에만 있어 상세에 "가상 예약할 수 있는 장소가 없어요"가 나왔다. 같은 곳이 이름이 달라 두 행으로 있고, 일정은 카카오 행을 골랐다. 숙소는 수정 요청으로 씨마크 호텔(시스템 행)로 바꾸자 예약할 수 있었다.
- 같은 날 추천 이유에도 "오죽헌은 목적 시설 검색 결과에 없어"라는 문장이 나왔다(2-4와 같은 GPT 문장 문제).
- 검토 방향: 가상 수량 연결을 장소 행 대신 좌표 근접(예: 300m)·이름 포함으로 찾거나, 후보 합칠 때 가까운 시스템 행을 우선한다.

## 4. 아직 브라우저로 확인하지 않은 것

- 실제 휴대폰 화면과 실제 위치 권한 허용(브라우저 375px 폭으로는 주요 화면 9개에서 가로 스크롤이 없는 것을 확인했다). 앱 내장 브라우저는 위치 권한이 거부 상태라 '내 위치로 찾기'는 거부 안내와, 좌표를 넣었을 때의 서버 처리만 확인했다(2026-09-26).
