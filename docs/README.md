## 범위와 남은 확인 사항

- 관리자 기능은 `AGENTS.md` 6절과 3.1 통합 변경 내역에 따라 **회원 관리로 제한**합니다. 관리자 여행지·관광지·숙소·음식점 CRUD와 키워드 CRUD 화면은 추가하지 않습니다. 요구분석서 3.1에 남아 있는 SFR-12 관리자 키워드 관리는 이 결정에 따라 구현 범위에서 제외한 항목입니다.
- 닉네임 중복 정책, 추적표의 이전 명세 참조는 아직 정리하지 않았습니다. 화면 추적표는 요구분석서 3.1 전체와 대조하지 않았으며 대조한 부분만 문서 앞쪽에 표시했습니다.
- ERD HTML과 같은 위치의 `_files` 폴더는 한 묶음으로 이동해야 합니다.
