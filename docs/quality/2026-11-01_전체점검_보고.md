## 4. 이미 알려진 한계 (다시 확인한 것)

- AI 요청 수 제한은 서버 메모리에 있어 재시작하면 초기화되고, 서버를 여러 대 두면 따로 센다. A1·B1을 같은 방식으로 고치면 같은 한계가 따라온다.
- 문장 분석은 요청 스레드에서 최대 25초 기다린다.
- 결제 대기 자동 만료와 관리자 예약 조회 화면이 없다(위 8).
- 같은 DB를 쓰는 앱이 둘이면 작업을 서로 가져간다. 게다가 시작할 때 `recoverInterrupted`가 다른 인스턴스가 처리 중인 작업까지 실패로 바꾼다. 무중단 배포와 IDE 테스트에서 주의해야 한다(E1).
- operation_logs를 1년 보관한 뒤 삭제하는 기능은 구현되지 않았다(DB 정의서 35행).
- HTTPS로 배포하면 `SESSION_COOKIE_SECURE=true`, 프록시 뒤면 `FORWARD_HEADERS_STRATEGY=native`를 켠다.
