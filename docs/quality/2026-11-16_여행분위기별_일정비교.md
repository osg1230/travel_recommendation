# 여행 분위기별 일정 비교 (2026-11-16)

[취향·감성 반영 계획](../ai/취향_감성_반영_계획.md) 3단계의 분위기 점수(7.3)가 실제 일정에서 장소 구성을 바꾸는지 확인했다.

## 진행 방법

- 로컬 웹 서버(8080, `sqlserver-windows` 프로필, 브랜치 `feature/place-value-score` `b4df779`)에서 **비회원**으로 진행했다.
- 조건 고르기 → 강원 · 바다 · 자차 · 2일 · 속도 상관없음 → 여행지 추천 → **강릉** 일정 만들기 → 숙소 포함, 출발일 2026-11-26(목), 출발지 비움. **분위기만** 한적한·활기찬·감성적인으로 바꿨다.
- 처음 실행한 활기찬·감성적인은 조건 입력 화면이 이전 선택을 기억해 분위기가 섞이고 바다 취향이 빠져(추천 화면 요약으로 확인), 결과에서 뺐다. 모든 선택을 지우고 다시 만든 결과만 적는다. 추천 화면 요약에서 조건이 맞는지 확인했다.
- GPT가 추천·장소 고르기를 하므로 실행마다 후보가 조금씩 다르다. OpenAI 호출은 추천 5회·일정 5회분(무효 2회 포함)이 있었다.

## 결과 요약

| 분위기 | 낮 관광지 | '고른 분위기와 어울리는 종류'가 붙은 곳 | 후보 중 어울리는 관광지 |
| --- | --- | --- | --- |
| 한적한 | 7곳 | 0곳 | 0~1곳 (산책로 1) |
| 활기찬 | 10곳 | 5곳 (해변 3, 시장 2) | 8곳 (해변 6, 시장 2) |
| 감성적인 | 7곳 | 3곳 (해변, 아르떼뮤지엄, 해안 산책로) | 약 8곳 (해변·전시·산책로) |

- **분위기 점수는 동작한다.** 활기찬은 시장 2곳(중앙시장·주문진수산시장)이 들어가고, 감성적인은 아르떼뮤지엄·해변이 앞에 왔다. 고른 이유 문구도 맞게 붙었다.
- **그러나 장소 구성은 크게 바뀌지 않았다.** 세 일정 모두 강문해변·경포대·아르떼뮤지엄·중앙시장 같은 곳이 반복된다.

## 원인

1. **후보에 분위기 종류가 거의 없다.** 후보는 여행 취향(바다)과 대표 관광지로 찾는다. 한적한 후보(수목원·휴양림·둘레길·호수 등)는 세 실행 모두 관광지로는 0~1곳이었다. 점수는 후보 안에서 순서만 바꾸므로, 후보에 없는 종류는 넣을 수 없다.
2. **해변이 활기찬·감성적인 둘 다에 걸린다.** 카카오 분류 "해수욕장,해변"이 활기찬(해수욕장)과 감성적인(해변) 낱말에 모두 맞아, 바다 여행에서는 두 분위기의 차이가 작다. 11월에 해수욕장을 '활기찬'으로 보는 것도 어색하다.

## 개선 방향 (결정 필요, 코드는 바꾸지 않음)

- 후보 찾기 단계에 분위기별 검색어를 더한다. 예: 한적한 → 수목원·휴양림·둘레길, 감성적인 → 카페거리·미술관·전망대, 활기찬 → 시장·야시장·테마파크. 바다 취향의 `ThemePlaces.SEARCH_WORDS`("해안산책로")와 같은 방식이다. TourAPI·카카오 검색 호출이 늘 수 있다.
- 해변·해수욕장은 분위기 낱말에서 빼거나 한 분위기에만 둔다.

## 세 일정 (낮 관광지, 저녁 관광)

| 분위기 | 1일차 | 2일차 | 저녁 관광 |
| --- | --- | --- | --- |
| 한적한 | 강릉중앙시장 → 사근진해변 → 아르떼뮤지엄 강릉 → 강문해변 | 송정해변 → 경포대 → 오죽헌 | 아들바위공원 |
| 활기찬 | 사근진해변★ → 참소리축음기박물관 → 경포대 → 아르떼뮤지엄 강릉 → 강문해변★ | 송정해변★ → 강릉중앙시장★ → 아들바위공원 → 소돌해안일주 산책로 → 주문진수산시장★ | 안목해변 |
| 감성적인 | 강문해변★ → 아르떼뮤지엄 강릉★ → 경포대 → 참소리축음기박물관 | 강릉중앙시장 → 아들바위공원 → 소돌해안일주 산책로★ | 경포해변 중앙광장 |

★ = 고른 이유에 '고른 분위기와 어울리는 종류'가 붙은 곳. 세 일정 모두 조건 확인 미충족 0, 서버 오류 없음.

## 같은 날 속도 비교에 대한 정정

같은 입력 방식 문제로 [여행 속도별 일정 비교](2026-11-16_여행속도별_일정비교.md)의 '보통' 실행은 바다 취향이 빠진 채 만들어졌다(작업 요청 JSON으로 확인). 느긋하게·알차게 실행에는 바다가 있었다. 속도는 라디오 버튼이라 맞게 들어갔고, 비교한 하루 장소 수·체류시간은 속도 규칙으로 정해지므로 결론은 같다. 다만 장소 종류의 차이는 이 때문일 수 있다.
