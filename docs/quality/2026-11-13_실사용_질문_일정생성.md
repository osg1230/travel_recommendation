# 실제 사용자 질문으로 만든 여행 일정 (2026-11-13)

페르소나 문서 대신, 사람들이 여행 전에 AI에게 실제로 물어볼 만한 문장 6개로 처음부터 끝까지 일정을 만들어 본 결과이다. 사용자가 직접 일정을 만들어 피드백하기 어려워서, 나중에 읽고 판단할 수 있게 결과와 눈에 띈 문제를 정리했다.

## 진행 방법

- 로컬 웹 서버(8080, `sqlserver-windows` 프로필, 브랜치 `feature/place-value-score` `5941fe5`)에서 **비회원**으로 진행했다.
- 흐름: 조건 입력 '문장으로 적기' → 여행지 추천 → **1순위 여행지**의 '일정 만들기' → 출발일·출발지만 적고 일정 초안.
- 시간(09:00~18:00), 체류시간, 하루 방문 수는 화면 기본값을 그대로 두었다. 문장에 날짜가 없으면 문장에 맞는 가까운 날짜를 골랐다.
- 화면이 조건을 고쳐 달라고 하면 사용자가 할 법한 수정을 한 번 했다(양평).
- 장소 운영시간·실제 동선·가격은 현장이나 공식 사이트로 확인하지 않았고, 일정 화면에 나온 정보로만 판단했다. 아래 '문제'는 화면을 읽고 판단한 것이라 실제와 다를 수 있다.
- 비회원 초안은 30분 뒤 만료돼 다시 열 수 없다. 일정 내용은 이 문서가 기록이다.

## 질문별 일정과 판단

### Q1 부모님과 속초 2박 3일 (자동차)

- 1일차: 서울 09:00 출발 → 12:10 도착 / 청초호 → 점심 함흥냉면옥 → 아바이마을 벽화골목 → 속초해수욕장 → 라마다호텔 속초(17:07) → 저녁 남경막국수 본점
- 2일차: 영금정 → 동명동성당('시간이 남아 한 곳 더') → 영랑호 → 점심 동명항생선구이 → 보광사('시간이 남아 추가') → 속초관광수산시장 → 숙소 → 저녁 **남경막국수 본점(1일차와 같은 집)**
- 3일차: 대포항전망대 → 척산온천휴양촌(120분) → 점심 섭죽마을 → 설악케이블카 → 신흥사('시간이 남아 추가') → 16:04 출발, 18:47 서울 도착
- 예상 경비: 약 40.1만~101.8만 원(3명)
- 좋은 점: 장소 사이 이동이 대부분 15분 안쪽이다. 온천·케이블카처럼 덜 걷는 곳이 들어갔고 식사가 모두 한식이다. AI 준비 안내가 겨울 바닷바람·미끄럼 대비를 짚었다.
- 문제
  - "많이 걷는 곳은 빼 주세요"가 여유 일정으로 인식되지 않았다. 2일차 관광 5곳 중 2곳이 '시간이 남아 추가'다. `RelaxedPace`가 찾는 말(여유롭게·빡빡하지 않게 등)에 '많이 걷지 않게'는 없다.
  - 이틀 저녁이 같은 식당이다. 2일차 저녁의 고른 이유는 "앞 끼니(냉면·해물·생선)와 다른 음식"인데, 바로 전날 저녁(국수)과는 같은 집이다.
  - 아바이마을 벽화골목·신흥사(설악산 입구)는 걷는 거리가 있는 곳이라 무릎이 불편한 부모님께 맞는지는 확인이 필요하다.

### Q2 혼자 강릉 1박 2일 (대중교통, 예산 25만 원)

- 1일차: 서울 용산구 09:00 → 시외·고속버스 140분 → 11:30 도착 / 강릉중앙시장 → 점심 정은숙초당순두부 → 경포호 → 강문해변 → 세인트존스호텔 → 저녁 강문어화횟집 → **저녁 관광 안목해변** → 21:45 숙소
- 2일차: 송정해변 → 해파랑길 38코스(120분) → 점심 옹심이장칼국수 감자바우 → 정동진 해변(버스 48분) → 16:28 출발, 18:58 서울 도착
- 예상 경비: 약 15.7만~39.5만 원(1명). 예산 충족은 판단하지 않았다고 표시된다.
- 좋은 점: 구간마다 버스 번호·정류장·요금이 나온다. 지역 대표 음식(초당두부·옹심이)을 이유로 든 식당이 있다.
- 문제
  - "조용히 쉬다 오고 싶어요"도 여유 일정으로 인식되지 않았다. 1일차는 낮 관광 3곳 + 저녁 관광 1곳, 2일차는 2시간 걷기(해파랑길)가 들어갔다.
  - KTX를 말했지만 직행 버스로 계산됐다. 집 ↔ 터미널 이동은 빠져 있다고 안내된다.
  - 정동진 해변에서 서울까지도 140분으로 넣었다(근거 문구가 '여행지행 기준'). 정동진 → 강릉 시내 이동이 빠졌을 수 있다.
  - 혼밥 요청인데 저녁이 횟집이다. 1인 주문이 되는지는 확인하지 않았다.

### Q3 친구 6명 부산 2박 3일 (대중교통)

- 1일차: 자갈치시장 → 국제시장 → 김민부전망대 → 점심 초량밀면 → 롯데호텔 부산 **14:33 도착, 17:44까지 숙소 휴식** → 저녁 기장손칼국수
- 2일차: 감천문화마을 → 송도해상케이블카 → 점심 빨간등대 영도본점(회) → 흰여울문화마을 → 숙소 → 저녁 **기장손칼국수(같은 집)**
- 3일차: 해동용궁사(68분, 환승 2회) → 기장시장 → 점심 원조기장손칼국수 → 죽성드림세트장 → 16:10 종료
- 예상 경비: 약 73.4만~186.4만 원(6명)
- 좋은 점: 사진 명소(감천·흰여울·죽성드림세트장)가 들어갔다. 지하철·버스 환승까지 안내된다.
- 문제
  - "밤에 놀 만한 곳"이 하나도 없다. 저녁 관광이 없고, 광안리·해운대 같은 곳도 빠졌다.
  - 1일차 오후 3시간을 숙소에서 쉰다. 관광 3곳 뒤 남는 시간을 채우지 않은 것으로 보인다.
  - 세 끼가 칼국수다(저녁 두 번은 같은 집). '국수'와 '칼국수'를 다른 음식으로 보아 "앞 끼니와 다른 음식"이라고 표시된다.
  - 추천 여행지가 부산 1곳뿐이다(지역을 정했으니 맞는 동작). 목적에 맞는 곳으로 김민부전망대 한 곳만 찾았다.

### Q4 연인과 양평 당일치기 (자동차)

- 처음 시도: 조건 보완 화면에서 "'서울 근교'에 맞는 여행지를 찾지 못했어요. 지역 칸을 '서울'처럼 고쳐 주세요."라고 안내했다. 근교로 나가려는 사람에게 '서울'을 권하는 건 어색하다. 지역을 '양평'으로 고쳤다.
- 고친 뒤 "'양평'은 아직 여행지 목록에 없어서 지역 대신 원하는 여행으로 옮겼어요"라는 안내가 나왔지만 1순위는 양평이었다. 다른 후보로 **강릉·순천**이 나왔는데, "당일치기·너무 멀지 않게"와 맞지 않는다.
- 일정: 서울 중구 09:00 → **115분(설매재자연휴양림 부근 기준)** → 11:10 도착 / 세미원 → 점심 두물머리연핫도그 → 두물머리 → 더그림 → 17:59 출발, 19:44 서울 도착
- 예상 경비: 약 6.2만~16만 원(2명)
- 좋은 점: 관광 3곳이고 가까운 곳끼리 묶었다. 하루가 빡빡하지 않다.
- 문제
  - 질문의 핵심인 **카페가 한 곳도 없다**. 여행 취향은 아무것도 고르지 않은 상태로 해석됐고(카페는 취향 선택지에 없음), 목적 문장의 '카페'가 장소 고르기에 반영되지 않았다.
  - 서울 → 양평 이동의 기준점이 일정에 없는 설매재자연휴양림이라 115분이 나왔다. 실제 첫 장소(세미원)까지는 더 짧을 것으로 보인다(확인하지 않음). 기존 '집 이동 기준점' 남은 문제와 같다.
  - 점심이 핫도그 가게다.

### Q5 아이와 경주 1박 2일 (자동차)

- 1일차: 대전 서구 09:00 → 160분 → 11:50 도착 / 경주오릉('시간이 남아 추가') → 점심 요석궁 1779(한정식) → 월정교 → 대릉원 → 첨성대 → 라한셀렉트 경주 → 저녁 마켓338(호텔 안)
- 2일차: 국립경주박물관(90분) → 황리단길 → 점심 향화정 → 불국사 → 석굴암('시간이 남아 추가') → 16:34 출발, 19:19 대전 도착
- 예상 경비: 약 17.1만~38.6만 원(**인원을 정하지 않아 1인 기준**)
- 좋은 점: 대표 유적(대릉원·첨성대·불국사·석굴암·박물관)이 모두 들어갔고 동선이 짧다.
- 문제
  - 체험 장소가 0곳이다. 조건 확인표도 "체험·액티비티에 맞는 관광지는 확인된 후보에서 찾지 못했어요"라고 한다. 추천 이유에 쓴 경주엑스포대공원도 일정에 없다.
  - 유적·사찰만 하루 4곳씩 이어져, 질문의 "아이가 지루해하지 않게"와 반대다.
  - "아들이랑"인데 인원을 정하지 못해 경비가 1인 기준이다.

- 2일차: 한라수목원 → 사려니숲길 → 점심 교래흑돼지 본점 → 산굼부리 → 숙소 → 저녁 윤옥(일본식 라면)
- 3일차: 비자림 → 점심 제주일도 성산점(삼겹살) → 섭지코지 해안산책로 → **우도(차로 28분, 15:40~17:40)** → 71분 → 19:01 숙소 → 저녁 김재훈고사리육개장(19:45)
- 4일차: 가문이오름 → 올레길 6코스(120분) → 점심 검은여닭도가니 → 올레길 7코스(120분) → 17:15 종료
- 예상 경비: 약 42.6만~102.6만 원(2명, 연인으로 추정)
- 좋은 점: 오름 3곳, 흑돼지 2끼, 숲·폭포·해안이 고르게 들어갔다.
- 문제
  - **우도를 자동차로 28분 가는 곳으로 넣었다.** 배 시간과 승선 대기가 없고, 17:40에 우도를 떠나는 것으로 되어 있어 마지막 배 시간 확인이 필요하다.
  - 3박 모두 제주시내 체인 호텔이다. "감성 숙소"는 반영되지 않았고, 서귀포에서 끝나는 1일차는 숙소까지 78분을 돌아온다.
  - 첫날 공항 도착, 마지막 날 공항 이동이 없다(2026-11-10에 적은 방향 결정 필요 문제). 마지막 날에 올레길 2코스(4시간 걷기)가 들어갔다.

## 공통으로 보인 문제 (고칠 순서 제안)

1. **저녁 식당 반복**: 숙소 근처 저녁을 고를 때 전날 간 집을 다시 고른다(Q1, Q3). 코드로 확인한 원인: 여행 전체에서 쓴 식당을 기억하는 `usedRestaurants`는 있지만, 그날 관광지를 더 짧은 순서로 다시 넣으면(`ItineraryGenerator` 264~277행) 새 `DayBuilder`가 복사본에 기록해 그 뒤 끼니(숙소 근처 저녁 등)가 다음 날로 전달되지 않는다. 또 '먹은 음식'은 분류 이름이 같은지만 봐서 국수·칼국수를 다른 음식으로 본다.
2. **질문의 핵심 활동이 일정에 들어가지 않음**: 카페(Q4), 밤 놀거리(Q3), 체험(Q5), 감성 숙소(Q6). 여행 목적 문장은 추천 이유와 '목적에 맞는 곳' 검색에는 쓰이지만, 일정의 장소·숙소 고르기에는 약하게 반영된다. 미충족이 아니라 '확인 필요'로만 표시돼 사용자가 놓치기 쉽다.
3. **여유 요청의 다른 표현을 못 알아들음**: "많이 걷는 곳은 빼 주세요"(Q1), "조용히 쉬다 오고 싶어요"(Q2). 6개 중 5개 일정에 '시간이 남아 추가'가 있다. `RelaxedPace` 낱말 목록을 늘리는 것으로 일부는 해결된다.
4. **이동 기준점과 섬 이동**: 양평 이동이 일정에 없는 장소 기준(Q4), 정동진 귀가 시간(Q2), 우도 배 이동 없음(Q6).
5. **추천 단계의 거리 감각**: '서울 근교 당일치기'에 강릉·순천이 후보로 나오고, '서울 근교'를 '서울'로 고치라고 안내한다(Q4).
6. **인원 추정**: "아들이랑"(Q5)처럼 동행이 문장에 있어도 인원을 못 정하면 1인 기준 경비가 나온다.
7. **긴 숙소 대기**: Q3 1일차 14:33~17:44 숙소 휴식.

## 참고: 여러 탭 동시 사용

이번에 여러 탭에서 동시에 진행하다가, 한 탭(Q4)의 조건 보완 화면에서 '수정한 조건으로 추천받기'를 누르자 **다른 탭(Q3)의 추천 결과로 이동**했다. 코드로 확인하니 설계된 동작이다. 조건 보완 상태는 세션에 하나만 두고, 화면이 최신이 아니면(`revision` 불일치) "조건 수정 화면이 최신이 아니어서 가장 최근에 요청한 추천을 보여 드려요" 안내와 함께 최근 추천으로 보낸다(`TravelConditionReviewController.staleDirect`). 문장 분석도 세션당 한 번에 하나만 처리해, 다른 탭 하나는 '추천을 준비 중이에요'에서 멈췄다. Q4는 처음부터 다시 입력해 진행했다.
