## 주요 한계

- 여행지 28곳 중 관광지 시스템 데이터는 강릉·부산·경주·속초·양양·울산뿐이고, 나머지 22곳은 장소 목록에서 카카오 검색(24시간 캐시)으로 채운다. 광주 도심(옛 광주광역시 5개 구)은 전남광주통합특별시(2026-07-01) 한 지역명으로 묶을 수 없어 여행지에 넣지 않았고, 광주·전남 선택은 여수·순천·담양으로 찾는다. 주변 지역 추천은 기준 터미널이 있는 6곳에서만 동작한다.
- 운영시간·휴무는 TourAPI 원문 중 `매주 O요일`·단순 시간만 판정하고 공휴일·임시휴무·복합 조건은 확인 필요로 둔다. 참고 가격은 GPT 웹 검색 결과라 날짜·객실별 요금이 아니며(숙소는 동적 페이지가 많아 못 찾는 경우가 많다), 예산 적합성은 여전히 확인 필요다. 저장 일정에는 저장·수정안 적용 당시 조회한 가격을 조회 시각과 함께 옛 참고값으로 보여 준다.
- 저녁 식사: 숙박하는 날(마지막 날 제외)은 숙소 도착·휴식 뒤 18시 무렵 숙소 근처 식당에서 넣는다(21시까지 끝날 때만, 2026-09-23). 마지막 날·당일 여행은 하루 종료가 19:00 이후이고 17시 이후까지 관광이 이어질 때만 넣는다. 식사·숙소·날짜는 수정안에서 바꿀 수 없고 이전 버전 복원은 없다. 저장 일정으로 다시 만든 수정 초안은 저장한 시각·장소만 옮기며, 필수 방문 장소 설정·AI 안내·주변 지역·참고 가격은 이어지지 않는다.
- TAGO 버스 자료는 당일 배차만 주고 구간별로 비어 있는 곳이 많아, 배차 0건은 '판단하지 못한 지역'으로 안내한다.
- 주변 지역 추천은 일정 초안 화면에만 있고 저장 일정 상세에는 표시하지 않는다. 조건 결과표는 저장 당시 결과로 저장 상세에 보여 준다.
- 가상 예약 수량은 SYSTEM 숙소 3곳·관광시설 2곳의 2026-10-01~12-31뿐이다. 숙소 가격은 한 날짜(2026-11-18) 판매가 참고가, 동궁과 월지 관람료는 검색 결과 기준이다. 결제 대기 자동 만료와 관리자 예약 조회 화면은 없다.
