- 검색(`OpenAiVerificationClient`): 참고 가격과 같은 Responses API `web_search` 도구·구조화 출력. 답은 가능(YES)/불가(NO)/못 찾음(UNKNOWN)·근거 1~2문장·출처 URL이고, 출처가 실제 검색 결과 목록에 있어야 하며 서버가 그 페이지를 열어 장소 이름이 있으면 VERIFIED, 못 열면 UNVERIFIED, 근거 없으면 NOT_FOUND다(`PricePageChecker.mentions`). 결과는 `Result.verifications`(`CheckAnswer`)에 붙이고 장소 `details_json.aiChecks`에 주제별로 보관해 같은 질문은 7일(못 찾음 24시간) 재사용한다(`PlaceCheckDetails`).
- 버튼: 초안 화면 '확인 필요 항목 AI로 찾아보기 (N개)' → `POST /itineraries/{id}/verify`(세션당 30초 간격, 24시간 안 재사용) → 결과 절(주제·장소·판정·근거·출처 확인 여부·출처 링크)과 일정 항목의 "AI 확인(반려동물 동반): 가능 · … · 출처에서 장소 이름 확인" 줄, 조건 확인표의 '반려동물 동반'·새 '여행 목적 활동' 항목 요약("AI 웹 검색 N곳: 가능 a곳(…) · 불가 b곳 · 못 찾음 c곳 · 출처 확인 d곳")에 반영한다. 검색 결과라 충족으로 올리지 않는다.
- 자동 실행(`VERIFY_AUTO=true`): 일정 작업에서 초안 생성 → 반려동물 정보 → AI 확인 검색(40초 한도) → AI 준비 안내 순으로 돌려, 안내 입력에 항목별 `aiChecks`를 넘긴다(지시문: "검색 결과에 따르면"처럼 출처가 검색임을 드러내고 확정 사실처럼 쓰지 않는다). 버튼으로 찾은 결과는 안내가 이미 만들어진 뒤라 안내 문장에는 들어가지 않는다.
- 비용(OpenAI 공식 요금표 2026-10-11 확인): gpt-6-luna 입력 $0.10·출력 $0.50/1M 토큰, 웹 검색 도구 호출 $10/1,000회(검색 내용 토큰은 모델 요금). 질문 1개 ≈ $0.01+토큰 ≈ 약 $0.012, 초안 1개 최대 10개 ≈ $0.12. 웹 검색 없는 추천~초안 한 번(조건 해석·목적 검색어·추천·관광지 순서·일정 보조 5회)은 토큰 약 2만 개 ≈ $0.005.

## 주요 한계

- 여행지 28곳 중 관광지 시스템 데이터는 강릉·부산·경주·속초·양양·울산뿐이고, 나머지 22곳은 장소 목록에서 카카오 검색(24시간 캐시)으로 채운다. 광주 도심(옛 광주광역시 5개 구)은 전남광주통합특별시(2026-07-01) 한 지역명으로 묶을 수 없어 여행지에 넣지 않았고, 광주·전남 선택은 여수·순천·담양으로 찾는다. 주변 지역 추천은 기준 터미널이 있는 6곳에서만 동작한다.
- 운영시간·휴무는 TourAPI 원문 중 `매주 O요일`·단순 시간만 판정하고 공휴일·임시휴무·복합 조건은 확인 필요로 둔다. 참고 가격은 GPT 웹 검색 결과라 날짜·객실별 요금이 아니며(숙소는 동적 페이지가 많아 못 찾는 경우가 많다), 예산 적합성은 여전히 확인 필요다. 저장 일정에는 저장·수정안 적용 당시 조회한 가격을 조회 시각과 함께 옛 참고값으로 보여 준다.
- 저녁 식사: 숙박하는 날(마지막 날 제외)은 숙소 도착·휴식 뒤 18시 무렵 숙소 근처 식당에서 넣고, 그 뒤 저녁 관광 1곳과 숙소 복귀까지 22시 안에 끝날 때만 넣는다(2026-09-25). 마지막 날·당일 여행은 하루 종료가 19:00 이후이고 17시 이후까지 관광이 이어질 때만 넣는다. 수정안에서 여행 날짜·기간은 바꿀 수 없고(2026-09-25부터 식당·숙소·이동수단·관광지 더하기는 가능) 이전 버전 복원은 없다. 저장 일정으로 다시 만든 수정 초안은 저장한 시각·장소와 사용자 조건(필수 방문 장소·하루 방문 수·예산 기준, 2026-09-29부터 저장한 일정만)을 옮기며, AI 안내·주변 지역·참고 가격은 이어지지 않는다. 하루 방문 수를 정했으면 저녁 관광도 그 수에 센다(2026-09-29).
- TAGO 버스 자료는 당일 배차만 주고 구간별로 비어 있는 곳이 많아, 배차 0건은 '판단하지 못한 지역'으로 안내한다.
- 주변 지역 추천은 일정 초안 화면에만 있고 저장 일정 상세에는 표시하지 않는다. 조건 결과표는 저장 당시 결과로 저장 상세에 보여 준다.
- 예약(체험) 대상은 모든 숙소와 입장권을 끊는 분류의 관광시설(박물관·아쿠아리움·테마파크 등, 2026-10-05부터)이다. 객실 종류·가격·입장료는 체험용 값이고, 식당은 대상이 아니다. 시드 숙소 3곳의 기준가는 한 날짜(2026-11-18) 판매가 참고가, 동궁과 월지 관람료는 검색 결과 기준이다. 결제 대기 자동 만료와 관리자 예약 조회 화면은 없다.
