# 화면–요구사항 추적표

기준일: 2026-10-28 | 요구사항 기준: `창프2_요구분석서 3.1_통합최종본.docx`(2026-10-28 본문 갱신) | 화면 기준: [최종_화면_ID_정리.txt](최종_화면_ID_정리.txt)의 UI-01~UI-21

## 1. 작성 기준

- 요구분석서 3.1의 기능 요구사항 72개(SFR-01-01~SFR-17-02)를 모두 대조했다. 우선순위는 3.1 본문 기준이다(가상 예약·결제 R2). SFR-12-01은 2026-10-11에 제외로 표시했다가 2026-10-28 사용자 결정으로 다시 포함해 구현했다(원래 우선순위 R1).
- 화면 ID는 설계 당시의 UI-01~UI-21을 유지하고, 실제 구현에서 화면 하나가 템플릿 여러 개로 나뉘었거나 다른 화면 안의 영역으로 들어간 경우 2절에 그대로 적었다. 새 화면 ID는 만들지 않았다.
- 근거는 현재 템플릿(`src/main/resources/templates`)과 컨트롤러 경로, 그리고 `docs/progress.md`의 브라우저 확인 기록이다. 이번 대조에서 브라우저를 새로 돌리지는 않았다. 화면 이미지 21장과의 시각 대조도 하지 않았다(이미지는 참고 자료, AGENTS.md 16절).
- 이전 명세(v1.5) 기준으로 작성했던 표(SFR 71개, SFR-12-02·03, SFR-17-03·04 포함)는 이 표로 대체했다. 그때의 확인 기록은 부록에 남겼다.
