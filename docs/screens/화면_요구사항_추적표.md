# 화면–요구사항 추적표

프로젝트: AI 기반 국내 여행 일정 추천 서비스

## 1. 작성 기준과 범위

- 2026-09-15 부분 갱신: 현재 `docs/requirements/창프2_요구분석서 3.1_일정배치방식반영_최종본.docx`에 맞춰 SFR-02~03의 조건 질문·답변 보완과 SFR-08-04의 AI 수정안을 반영했다. 아래 이전 원본 기준과 다른 항목은 이번에 전체 재검증하지 않았다.

- 화면 기준: 「최종_화면_ID_정리.txt」의 UI-01~UI-21. 기존 이미지 내부 번호는 사용하지 않는다.
- 요구번호·요구사항명·우선순위 기준: 요구분석서 3.1(2026-09-13)의 요구사항 목록. [공통 적용 기준](../requirements/적용기준.md)의 제외·예외를 함께 적용한다.
- 관리자 업무는 회원 조회·정상/이용 제한 상태 변경만 제공한다. SFR-12-01·QUR-06과 UI-17은 적용 제외하며 키워드 데이터는 배포로 관리한다. 가상 예약·결제는 R3이다.
- 3.1의 요구사항 목록 ID·이름·우선순위를 대조했다. 이전 관리자 CRUD 식별자 4개는 이력용으로 구분한다. 화면 이미지는 참고용이며 구현 완료를 의미하지 않는다.
- 표의 연결은 설계상 처리 위치를 뜻한다. 구현 완료나 모든 이미지에 해당 버튼이 이미 표현돼 있음을 뜻하지 않는다. 보완할 항목은 5절에 정리했다.
- 비회원은 여행 조건 입력과 추천·일정 결과 조회 가능. 일정 저장·수정·즐겨찾기·평가·개인 이력·예약·결제는 회원 기능이며 관리자 화면은 관리자 전용이다.

## 6. 점검 결과와 다음 사용 방법

- 화면 색인: 기존 UI-01~UI-21 중 UI-17 제외, 적용 20개(R3 3개 포함). 새 화면 ID 없음.
- 기능 식별자: 3.1 원본 67개를 대조하고 적용 66개의 처리 위치를 연결했다. SFR-12-01과 과거 식별자 4개의 제외 사유를 기록했다.
- 기타 식별자: DAR 14개, EIR 6개, SER 6개, QUR 7개, TER 8개를 모두 포함하며 QUR-06은 적용 제외한다.
- UI-01·UI-16의 진입·요약 역할 및 시스템 내부 요구사항은 별도 기능 ID를 임의로 만들지 않았다.
- 다음에는 5절의 버튼·팝업·상태 표시를 화면 상세 명세와 흐름도에 반영하고, 이 요구번호를 유지해 DB/ERD 및 테스트 항목으로 이어서 추적한다.
- 이 문서에서 확인한 연결은 설계 매핑이며 테스트 통과나 구현 완료 수치가 아니다.
