# 취향 찾기 문구와 이미지 생성 프롬프트

기준일: 2026-11-26. 문구는 `PreferenceDiscovery.QUESTIONS`(질문 24개, 장면 48개)에서 가져왔다.
이 문서는 ChatGPT로 취향 찾기 그림 48장을 만들 때 쓰는 프롬프트 모음이다. 아직 이미지는 만들지 않았고 화면에도 적용하지 않았다.

## 1. 사용 방법

1. ChatGPT 새 대화에 **2절의 공통 문구**를 먼저 보낸다. 화풍은 A(일러스트)와 B(실사) 중 하나만 고른다.
2. **3절의 장면 프롬프트**를 한 번에 한 줄씩 보낸다. 한 대화에서 계속 이어서 보내야 화풍이 유지된다.
3. 처음 2~3장으로 화풍이 마음에 드는지 확인한다. 마음에 들지 않으면 공통 문구를 고쳐 새 대화에서 다시 시작한다.
4. 받은 그림은 표의 **파일 이름**으로 저장한다. 예: `season-a.png`.
5. 그림이 대화 중간부터 화풍이 달라지면 "처음 그림과 같은 화풍으로 다시 그려 줘"라고 요청한다.

저장한 파일을 한 폴더에 모아 주면 크기를 맞춰 화면에 적용한다. 지금 화면은 `static/images/discover/`의 `.svg` 그림을 쓰고 있어, 적용할 때 파일 형식에 맞게 템플릿을 한 줄 고쳐야 한다.

## 2. 공통 문구 (대화 맨 처음에 한 번 보내기)

### 화풍 A. 일러스트 (추천)

```text
지금부터 국내 여행 서비스의 '취향 찾기' 화면에 쓸 그림을 여러 장 만들 거야.
내가 장면을 한 줄씩 보내면, 아래 규칙을 모두 지켜서 그림을 한 장씩 그려 줘.

[화풍]
- 따뜻하고 차분한 색감의 평면 일러스트. 굵은 외곽선 없이 면으로 표현하고, 은은한 질감을 넣는다.
- 색은 청록, 크림, 살구, 부드러운 파랑을 중심으로 쓰고 채도는 낮게 유지한다.
- 모든 그림이 한 사람이 그린 한 세트처럼 보이게 화풍, 색감, 묘사 수준을 똑같이 유지한다.

[구도]
- 가로로 긴 3:2 비율.
- 장면의 중심이 그림 한가운데에 오게 한다. 위아래 가장자리는 잘려도 괜찮게 여백을 둔다.
- 한눈에 무슨 장면인지 알 수 있게 단순하게 그린다.

[넣지 말 것]
- 글자, 숫자, 간판 글씨, 로고, 워터마크.
- 실제로 있는 특정 건물이나 관광지를 알아볼 수 있게 그린 것.
- 얼굴이 크게 보이는 인물. 사람은 작게, 뒷모습이나 옆모습으로만 그린다.

[배경]
- 한국의 국내 여행지 분위기. 한국의 산, 바다, 골목, 음식처럼 보이게 한다.

이해했으면 "준비됐어요"라고만 답해 줘.
```

## 3. 질문별 문구와 장면 프롬프트

각 표의 **화면 문구**는 지금 화면에 나오는 선택지이고, **보낼 프롬프트**는 ChatGPT에 그대로 붙여 넣는 한 줄이다.
한 질문의 A와 B는 화면에 나란히 놓이므로, 둘이 확실히 달라 보이는지 함께 확인한다.

| `season-b` | 겨울, 찬 공기 속에서 따뜻하게 쉬기 | 눈 내린 겨울 풍경이 보이는 창가. 담요를 덮고 김이 나는 따뜻한 차를 들고 쉬는 사람의 뒷모습. |

## 4. 받은 그림 확인할 것

- 글자나 로고가 들어가지 않았는지. 간판, 메뉴판, 책 표지에 자주 생긴다.
- 손, 얼굴, 젓가락, 자전거 바퀴처럼 어색하게 나오기 쉬운 부분.
- 같은 질문의 A와 B가 한눈에 구분되는지. 특히 아래는 비슷해지기 쉽다.
  - `view_spot-a`(해 뜨는 바닷가)와 `second_morning-b`(일출 보러 나가기)
  - `night-a`(야경 명소)와 `summer_night-b`(강변 야경)
  - `must_eat-b`(빵과 디저트)와 `afternoon-b`(빵집 찾아다니기)
  - `sea_time-b`(바다 카페)와 `afternoon-a`(전망 카페에서 책 읽기)
  - `winter_day-b`(눈 쌓인 산사)와 `mountain-b`(오래된 산사)
- 화풍과 색감이 앞 그림들과 같은지.
- 위아래가 조금 잘려도 장면의 중심이 남는지.
