최종 화면 ID 체계 및 기존 화면명 매핑
프로젝트: 3학년 창업 프로젝트
기준: docs/requirements/적용기준.md 및 요구분석서 3.1
정리일: 2026-09-13

1. 적용 기준

- 기존 UI-01~UI-21 번호를 유지하되 UI-17은 적용 제외한다. 적용 화면은 20개이며 R3 선택 화면 3개를 포함한다.
- 공통 → 회원 → 추천 → 일정 → 관리자 → R3 확장 순서로 정렬한다.
- 기존 식별자 UI-01부터 UI-21까지 유지하며 제외 번호를 다른 화면에 재사용하지 않는다.
- 기존 이미지 파일은 수정하지 않는다. 이미지에 적힌 기존 번호와 새 번호가 다르면 이 문서의 매핑을 기준으로 식별한다.
- 기존 번호는 제작 과정에서 중복·변경되었으므로 기존 화면명을 매핑 기준으로 사용한다.
- 같은 화면의 명칭 변형은 아래에 함께 표기하며, 별도 화면으로 계산하지 않는다.

3. 기존 번호 사용 시 주의사항

- 관리자 상세 명세에서 사용했던 UI-01 관리자 메인은 새 UI-16에 해당한다.
- 관리자 상세 명세에서 사용했던 UI-02 키워드 관리는 새 UI-17에 해당한다.
- 관리자 상세 명세에서 사용했던 UI-03 회원 관리는 새 UI-18에 해당한다.
- 그 밖의 기존 번호는 화면명과 함께 확인한다. 기존 번호만으로 새 번호를 추정하지 않는다.
- 문서에서 기존 이미지를 인용할 때는 다음과 같이 새 ID를 별도 캡션으로 표시할 수 있다.
  예: UI-16 관리자 메인 (이미지 내부 표기: UI-01)

4. 범위 및 미완료 사항

- UI-03 회원가입: 기존 대화에서 약관 동의 중심 이미지의 수정 필요가 지적되었다.
  현재 기준은 로그인 아이디(login_id), 비밀번호, 비밀번호 확인, 닉네임 입력이며 이메일 로그인을 추가하지 않는다.
  이 문서는 ID만 정리하며 해당 이미지 수정은 수행하지 않는다.
- UI-19 ~ UI-21은 선택적 R3 확장 화면이며, 실제 결제가 아닌 가상 예약·결제를 대상으로 한다.
- 과거 관리자 안의 '운영/예약·결제 내역 관리(R3)' 또는 'R3 운영정보 조회'는
  관리자 회원 관리 제한에 따라 적용 제외하며 별도 번호를 부여하지 않는다.
  사용자용 UI-21 예약·결제 내역과 동일 화면으로 간주하지 않는다.
- 관리자 업무는 회원 관리만 제공한다. 키워드 관리, 여행지 관리, 숙소 관리, 음식 정보 관리 화면은 제외한다. 키워드 데이터는 배포 SQL로 관리한다.
- 로그아웃, 회원 탈퇴 확인, 즐겨찾기 등록, 장소 평가 요약, 지도 길찾기,
  주변 지역 추천, 음식점 상세, 관리자 회원 상태 변경은 기존 화면의 버튼·영역·팝업으로 처리하며
  이번 체계에서 별도 화면 ID를 부여하지 않는다.

5. 검산

공통 2개 + 회원 5개 + 추천 4개 + 일정 4개 + 관리자 2개 + R3 확장 3개 = 적용 20개
기존 식별자 총 21개 중 UI-17 적용 제외
최종 ID 범위: UI-01 ~ UI-21
번호 중복: 없음
의도적 제외: UI-17(다른 화면 번호 변경 없음)
