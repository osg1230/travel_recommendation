카테고리

코드

현재 상태

코드는 조건 해석에 쓰여 바꿀 수 없습니다.

이 키워드의 카테고리가 사용 중지 상태라, 키워드를 사용 중으로 두어도 조건 입력 화면에 보이지 않습니다.

이름과 표시 순서

조건 입력 화면에 바로 반영됩니다. 이미 저장된 추천 요청·일정에는 그때의 이름이 그대로 남습니다.

이름 (고정)

0~999 사이 숫자이며 같은 카테고리 안에서 작은 숫자가 앞에 보입니다.

사용 여부

사용 중지하면 조건 입력 화면의 선택지에서 빠집니다. 이미 저장된 추천 요청과 일정의 조건 기록은 그대로 남습니다.

다시 사용하면 조건 입력 화면의 선택지에 다시 나타납니다.

키워드는 삭제하지 않습니다. 저장된 추천 요청이 이 키워드 번호를 기록하고 있기 때문입니다.
