코드

소속 키워드

현재 상태

코드는 조건 입력 화면의 질문과 연결돼 바꿀 수 없어요.

이름과 표시 순서

조건 입력 화면의 질문 문구와 순서는 화면에 고정돼 있어, 카테고리 이름과 표시 순서는 키워드 관리 목록에만 반영돼요.

0~999 사이 숫자이며 작은 숫자가 목록 앞에 보여요.

사용 여부

사용 중지하면 이 카테고리의 키워드가 조건 입력 화면에서 모두 빠져요. 키워드 하나만 빼려면 키워드 목록에서 그 키워드를 사용 중지하세요.

다시 사용하면 사용 중인 키워드가 조건 입력 화면에 다시 나타나요.

카테고리는 추가하거나 삭제하지 않아요. 조건 입력 화면의 질문 5개가 화면에 고정돼 있기 때문이에요.
