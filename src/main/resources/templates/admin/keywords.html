키워드 관리

조건 입력 화면에서 고르는 선택지(지역·계절·동행자·여행 취향·이동수단)를 관리해요. 바꾼 내용은 조건 입력 화면에 바로 반영돼요. 키워드는 삭제하지 않고 사용 중지해요.

새 키워드 추가

지금은 키워드를 추가할 수 있는 카테고리가 없어요.

지역·계절·이동수단·여행 분위기·여행 속도는 추천 규칙과 연결돼 있어 새 키워드를 추가할 수 없어요.

조건 입력 화면에 그대로 보이는 이름이에요. 예) 야경

영문으로 시작하는 영문·숫자·밑줄(_) 2~50자이며 대문자로 저장돼요. 예) NIGHT_VIEW. 저장한 뒤에는 바꿀 수 없어요.

0~999 사이 숫자이며 작은 숫자가 앞에 보여요. 비워 두면 맨 뒤에 놓여요.

· 카테고리 수정

사용 중지한 카테고리라 아래 키워드는 조건 입력 화면에 보이지 않아요.

아직 키워드가 없어요.

이름표시 순서코드 상태수정
· 이름 고정 수정·사용 여부

'이름 고정' 키워드는 지역 검색·계절 판단·경로 계산·여행지 분류가 이름을 그대로 쓰므로 표시 순서와 사용 여부만 바꿀 수 있어요.
